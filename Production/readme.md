# Production files
These are the production files!

The production files are what you need to make your own megaboard!

## Legend
- Top.step is the top part of the shell
- Bottom.step is the bottom part of the shell
- Firmware.uf2 is the firmware of the keyboard!\
- Gerbers.zip is the gerber files to submit to your PCB fab

## Note regarding gerbers
To get the results that the original megaboard looks like, change the PCB color to black.
